# PDF library

Place PDF files in this folder, then add one object per file to `library.json`.

```json
{
  "id": "geometry-notes-2026",
  "title": "Geometry Notes",
  "description": "A short description visitors can search.",
  "category": "Notes",
  "year": 2026,
  "pages": 48,
  "size": "3.2 MB",
  "file": "assets/pdfs/geometry-notes.pdf",
  "featured": true
}
```

The `file` value can also be a complete HTTPS URL when a large collection is stored on an external document host.
